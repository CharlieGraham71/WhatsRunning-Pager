# What's Running? - WiFi Pineapple Pager

A utility payload for the WiFi Pineapple Pager that shows:

- Running services
- Recon status
- Bluetooth status
- Resource usage
- Battery-draining processes

## Current Features

- Detects pineapd
- Detects blue5
- Detects hostapd
- Detects dnsmasq

## Planned Features

- CPU monitoring
- Memory monitoring
- "Why Is My Pager Hot?"
- Process termination
- Payload detection
- Health scoring
